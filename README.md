# Portfolio Pixie

Build a modern, professional and fully responsive Personal Portfolio Builder using React with JavaScript, Vite, and CSS.

Project Goal

Create a portfolio builder for college students and freshers. Users should enter their information in an editor and see their portfolio update instantly in a live preview.

Tech Stack

React

JavaScript

Vite

CSS

React Icons or Lucide Icons

Do not use TypeScript.

Pages & Features

1. Landing Page

Create an attractive homepage with:

Hero section

Heading: "Build Your Professional Portfolio"

Short description

"Create My Portfolio" button

Clean modern design

Smooth scrolling

Subtle animations

2. Portfolio Editor

Create a user-friendly editor with separate sections for:

Personal Information

Name

Profile photo

Professional title

About/Bio

Email

Phone

Location

Education

Degree

Institution

Year

Description

Skills

Skill name

Skill level

Projects

Project title

Description

Technologies used

Project link

Certifications

Certificate name

Organization

Date

Achievements

Achievement title

Description

Social Links

GitHub

LinkedIn

Other relevant links

3. Live Portfolio Preview

Create a real-time preview beside the editor.

When the user changes any information in the editor, the portfolio preview must update immediately without refreshing the page.

The preview should contain:

Home/Hero

About

Skills

Education

Projects

Certifications

Achievements

Contact

4. Template Selection

Provide 3 portfolio templates:

Minimal

Professional

Modern

Users should be able to switch templates and instantly see the selected design in the preview.

UI/UX

Clean and professional interface

Modern typography

Good spacing and alignment

Attractive cards and buttons

Smooth hover effects

Subtle animations

Responsive on mobile, tablet and desktop

Simple navigation

Easy-to-use forms

Avoid unnecessary complexity

React Structure

Use reusable React components such as:

Navbar

Hero

PortfolioEditor

PersonalInfoForm

EducationForm

SkillsForm

ProjectsForm

CertificationsForm

AchievementsForm

TemplateSelector

PortfolioPreview

Footer

Use React state to manage the form data and update the preview in real time.

Important

For this version, build frontend only.

Do NOT add:

Backend

Database

Authentication

AI integration

Payment system

Use realistic sample student data when the application initially loads so the UI looks complete.

The final result should look like a polished, real-world portfolio builder rather than a basic demo project.
